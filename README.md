# Диагностика МБП вар3

Новая версия статического приложения для диагностики потребности в управленческом учете на базе варианта 2.

## Запуск

Откройте файл `index.html` в браузере.

## Логика

- вопросы 1-6 формируют профиль бизнеса;
- вопросы 7-18 дают баллы риска по деньгам, прибыли и отчетности;
- вопрос 18 уточняет, используются ли в работе отчеты;
- вопросы 19-20 решающе определяют, какие отчеты предложить;
- вопрос 15 не влияет на баллы, если в бизнесе одно направление;
- итог показывает уровень риска, рекомендации по отчетам и следующий шаг;
- управленческий баланс предлагается только при выборе роста бизнеса, налоговый календарь из рекомендаций убран.

Данные не отправляются на сервер и остаются в браузере.
